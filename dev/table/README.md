# 表格独立预览

从仓库根执行 `npm ci` 后，运行 `npm run dev:table`。命令先构建，再在 `http://127.0.0.1:8293` 启动只监听本机的服务；Ctrl+C 停止。端口可用 `TABLE_PORT` 环境变量调整。端口被占用会报错，不接管已有服务。修改源码后重新构建并刷新页面。

页面装配生产表格、提示词编辑器、生成列和文档控制器。两个实例各自拥有内存文档与历史；保存预览只保存到页面内存，刷新恢复合成夹具。素材来自本服务的合成 `/view`，不读用户 input，不修改生产素材校验。

基础模式显示服务不可用原因并保留列配置；完整扩展模式通过绑定的模拟服务提供合成生成结果。可选择延迟、错误、不可用状态，检查卸载、重挂、空表、焦点和溢出。没有模型连接或真实任务提交；优化服务始终不可用。

`npm run test:table` 执行模型、票据、剪贴板与扩展合同用例。`npm run test:table:ui` 启动独立服务器并运行 Playwright 浏览器用例，默认使用已安装 Chrome；`TABLE_BROWSER=chromium` 可使用已安装的 Playwright Chromium。不要复用占用 8293 的其他服务。结果与首失败位于忽略目录 `.local/modularity/`。

浏览器模拟不能替代 ComfyUI 模式、原生保存、Slot、真实模型或性能验收。`dev/` 不进入 web 构建、隔离宿主快照或候选产品包。
