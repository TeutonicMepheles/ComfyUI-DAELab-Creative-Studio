# 开发指南

本仓库是后续新功能的唯一编辑入口。当前为未发布的开发版本；旧安装与数据保留，
M6 累计验收完成前不发布、不切换用户生产环境。

## 编辑与构建

- 前端源代码：`frontend/src/`；构建产物：`web/`，不要只修改产物。
- 后端与 ComfyUI 接入：`backend/`；兼容读取：`compat/`。
- 功能回归：`tests/`；现有架构与交互合同：`docs/architecture/`。
- 本机运行数据、失败记录与实验：`.local/`，已从 Git 和产品打包排除。

```powershell
npm ci        # 首次准备依赖；已有 node_modules 时无需重复
npm run build
npm run check # 提交涉及产品行为的修改时运行相关检查
```

前端构建后刷新开发页面；Python 后端修改后重启独立开发宿主。
新增功能按改动范围验证，不要求每次开发都重新执行完整迁移矩阵或 44 次模型评估。

## 独立 ComfyUI

开发宿主使用独立 user/input/output/temp，只安装本包，不同时加载旧 Canvas 与业务库。
可以将本仓库链接到该宿主的 `custom_nodes/ComfyUI-DAELab-Creative-Studio`，
这样前端构建可直接被开发宿主读取。原 8000 服务保持独立。

已有 `tools/host/prepare_isolated.py` 可创建 CPU 模式的独立快照环境；
用 `--help` 查看宿主、Python、包路径和端口参数。快照环境在停止后用
`--refresh-package` 显式更新，不会自动同步源码。

本机现成开发入口和启动脚本由本地交接记录提供，不将机器路径或运行数据作为产品配置提交。
CPU 开发入口适用于编辑、界面和保存功能；真实模型生成需要单独配置本地模型运行环境。
