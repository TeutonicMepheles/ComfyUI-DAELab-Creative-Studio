# P-M13 模型与提供方管理

2026-11-02。本文件定义模型与提供方管理的产品行为。当前实现采用显式本地模型配置，
本文件中的自动发现和统一可用性状态是目标行为，不代表已经实现或完成宿主验收。

## 范围

首版覆盖：

- ComfyUI 本地图片模型。
- ComfyUI 本地视频模型，包括 FL 与 Ref。
- 本地 Qwen / Ollama LLM。
- 2026-11-04 起移除 DeepSeek 云 API 文本通道（独立密钥通道）；文本生成与优化默认使用
  本地 Qwen / Ollama，Comfy 工作区积分的文本模型（如 GPT-6 Luna）保留。

后续提供方沿用相同目录、状态和消费合同。模型与提供方管理不执行推理，不拥有任务账本，
也不改变各任务资源准入规则。

提供方管理同时发布只读控制和进度能力，包括是否支持查询原任务、提供方取消、作用域内
中断、幂等查询和单任务数值进度。数值进度只用于单任务生成；成组任务由 `P-M11` 使用
完成计数。具体暂停、打断、继续、重启和进度状态由 `P-M11` 决定，模型选择模块不直接
操作任务。

## 用户目标

- 服务启动、应用打开或宿主重连后，自动建立当前机器可用的模型目录。
- 用户在生成节点和 LLM 优化节点中看到一致、可解释的模型可用状态。
- 配置变化或页面刷新后，无需逐节点重新读取即可恢复当前可用模型。
- 已保存工作流继续引用稳定逻辑模型；机器路径或服务状态变化不能静默改成另一模型。

## 核心对象

| 对象 | 定义 |
| --- | --- |
| 提供方 | 执行模型运行或 API 调用的边界，例如 ComfyUI 本地（含 Comfy 账户积分节点）、Ollama。 |
| 逻辑模型 | 工作流和业务配置引用的稳定产品模型身份。 |
| 运行时绑定 | 当前宿主上的节点、文件、清单、端点和提供方配置。 |
| 能力快照 | 当前逻辑模型支持的类型、模式、参数、素材约束及可用状态。 |
| 可用性状态 | 公开给选择控件的可选、检测中或不可用状态；内部检测原因单独记录。 |

工作流保存逻辑模型身份和用户选择。物理路径、文件哈希、Ollama 清单及云端节点
端点属于机器配置或运行时状态，不写入工作流业务数据。

## 自动发现与刷新

宿主就绪后执行一次低成本发现，不加载 GPU 模型，不发送计费请求。以下事件使相关快照
失效并重新检测：

- ComfyUI 服务启动或重连。
- 页面刷新或应用重新打开。
- 本地模型配置发生变化。
- 本地模型装配文件、Ollama 清单或 Comfy 目录发生变化。
- 用户选择“重新检测”。
- 提交任务前再次确认所选模型和提供方仍满足能力要求。

检测结果由 `P-M13` 统一发布。`P-M08` 提示词与 LLM、`P-M10` 图片与视频生成及多维表格
消费同一结果，不各自探测模型。

## 提供方检查

| 提供方 | 基础检查 |
| --- | --- |
| ComfyUI 本地图片/视频 | 所需节点、模型类别、文件是否存在、宿主解析路径、文件哈希及声明的生成模式。 |
| 本地 Qwen / Ollama | 回环服务是否可达、已安装模型列表、注册清单、六个 blob、模型名称和 digest。 |

文本提供方检测只读取本地 Ollama 服务、注册清单与模型文件，不发起计费请求。2026-11-04
起不再有云 API 文本通道，因此不读取、不保存任何云密钥，也不显示其状态。

本地检测不自动启动 Ollama、不下载模型、不用其他权重或量化版本替换缺失模型。Ollama
未运行时模型进入不可用状态，不自动启动外部进程，也不在模型选择界面解释原因。

## 模型列表状态呈现

生成节点、LLM 优化节点和多维表格的模型选项列表采用隐式状态提示，不显示常驻文字
Tag，也不展示可用性检测的错误说明。模型名称和提供方来源仍单独显示。

模型选择器属于创作控件，不是诊断界面。模型为什么不可用、缺少哪个节点或文件、哪项
哈希或凭据检查失败，均写入结构化日志；选项本身只表达当前能否选择。

| 状态 | 视觉与交互 |
| --- | --- |
| `可用` | 保持普通模型选项样式，可以选择并进入参数配置；提交前仍执行最终校验。 |
| `检测中` | 模型选项名称后显示加载圆环；检测结束前不得提交任务。 |
| `待验证` | 保持普通、可选择的选项样式；首次提交时验证。验证失败后阻止提交、更新为不可用并记录日志，不在界面解释原因。 |
| `不可用` | 整个模型选项置灰并禁用，不能选择或提交；不显示原因、错误提示或诊断详情。 |

加载圆环必须提供“正在检测此模型”的可访问名称。不可用状态除置灰外，还应通过禁用
语义或不可用光标表达，不能只依赖颜色；辅助技术只需获知“不可用”，不需要获知底层
原因。

列表行为：

- 可用模型保持默认外观，不额外显示勾选标签或“可用”文字。
- 当前模型从可选变为不可用时，保留其逻辑身份和可见选择，将其控件置灰禁用。
- 不静默选择其他可用模型，不改变工作流中的模型 ID。
- 检测完成后原位更新模型行，不重复生成列表项。
- 状态变化不能关闭用户正在编辑的配置，也不能清除未提交草稿。
- 模型选项较多时，加载圆环不能导致菜单横向溢出；键盘、焦点和读屏名称保持可用。
- 可用性检测不得在模型菜单、节点、Toast 或内联提示中显示底层错误。原因写入宿主日志，
  并保留 provider、逻辑模型、检测阶段、错误代码和时间，不记录密钥或文件内容。

选中的模型控件在不可用时同步置灰禁用；检测中时同步显示加载圆环。待验证状态不增加
常驻视觉标记。

## 匹配与冲突

- 自动匹配只接受产品支持且能力完整匹配的逻辑模型。
- 同一逻辑模型存在多个候选时，优先使用用户明确保存的提供方和绑定；仍不唯一时标记为
  “模型身份冲突”，不猜测。
- 当前工作流引用的模型不可用时，保留原配置并将原因写入日志，不自动回退到云端、其他量化
  版本或相邻模型。
- 用户显式切换模型时，只迁移新模型声明支持的设置；无效隐藏参数不继续提交。

## 本地 Qwen 图像尺寸选择（2026-11-03）

来源：Raft #Comfy-Canvas-Studio:e62eb3ab，用户消息 e62eb3ab。本节是产品要求，尚待实现与宿主验收。

- Qwen-Image-2.1 Turbo 的生成节点尺寸面板提供“自动”及图形加比例文字的可视化选项，
  不要求用户手输宽度和高度。表格与生成节点共用模型能力及参数换算。
- 只展示该模型实际支持的比例；图形外框比例与文字一致，选中状态和键盘焦点可辨认。
  后端按模型范围与步长得到合法宽高，不能将所有比例静默换成同一方图。
- 含参考图时，“自动”使用第一张有效参考图的宽高比，按模型尺寸约束换算；无参考图时
  使用模型默认尺寸。参考图顺序保持稳定。比例保留允许有尺寸步长造成的舍入，验收记录实际值。
- 无法可靠取得参考图尺寸时给出可理解的提示或要求选择固定比例，不静默伪装自动匹配成功。
  第一张参考图改变后，下一次提交重新计算；已提交任务的冻结输入不被后续编辑改写。
- 显式固定比例不因接入参考图而被覆盖；保存重开保持选择。旧工作流的自定义宽高保留原值，
  不因打开新面板就改写；不匹配新预设时须明确呈现原配置，用户选择后再转换。

具体比例清单和宽高映射由实际模型能力验证后交付，不能以其他提供方的参数替代。
真实生成及效果验收见 [模型说明](../MODELS.md)。

## 模型名后的来源胶囊（2026-11-04）

本轮按用户 d9fb6216 提供的参考图，在模型名后添加简短胶囊；这是产品规则，尚待宿主验收。

- “本地 / API”描述实际执行路由，从统一模型目录元数据读取，独立于显示名和模型 ID。
  同名模型在不同提供方可有不同来源；切换模型时同步更新，不能靠名称关键词推断。
- “开源 / 闭源”描述模型信息，不能由运行位置推断。只有目录具有可核实的明示信息时才展示；
  来源不明时省略该属性，不能把本地一律写为开源或 API 一律写为闭源。
- 已明确为本地开源的模型可合并显示“开源本地”；API 与闭源同时成立时可显示“API · 闭源”。
  胶囊不修改模型身份、权限、可用性或费用，不添加升级/VIP等参考图里的商业信息。
- 2026-11-04 用户 52b87b70 更新：本地胶囊使用青绿、API 使用蓝紫主题色，列表与已选项一致；
  保留文字区分，不只靠颜色。模型列表与触发项的字体/图标一致、对齐及向上展开按 P-M10 规则。
- 文本、图片、视频及表格模型选项使用同一来源依据；窄面板保持名称和胶囊可读，
  不能遮挡选择状态、参数或键盘焦点。

追踪：F-SYS-022 / AC-SYS-022-004。模型来源标签不代表已安装、可运行或实测通过。

## 模型选择悬浮备注（2026-11-06）

文本/图片/视频三类生成节点的模型选择控件，鼠标悬浮时显示小字备注，平时列表保持简洁。

- 只列该模型**实际**的基础参数与针对性能力，不写画质/速度承诺：
  - 量化精度：从实际权重名识别（`Q\d+_K(_M/S/L)`、`NVFP4`、`INT8`、`BF16`、`FP16`、`FP32`、
    `W\d+A\d+`、`AWQ`）。
  - 采样与步数：如 `euler · 25 步`、`res_multistep · 20 步`、`lcm · 6 步`；加速项标注
    「加速 8 步（已绑定适配器）」。
  - 针对性能力：如 首尾帧 2 图、图片参考 1–9 图、文生视频。
- 字段取当前实际模型与工作流的绑定能力；未知项不写、不猜测；「低配/高配」只描述档位的
  量化与采样差异，不写成「画质更好」「更快」等未实测结论。
- 备注不遮挡选项、参数或键盘焦点；鼠标悬浮与键盘聚焦均可读，窄窗不溢出、不抢点击。

## 数据与安全

- 2026-11-04 起不再存在云 API 文本密钥；宿主若仍留有旧环境变量，产品不读取，也不写入
  工作流、任务快照、账本、日志或诊断导出。
- 诊断日志只报告凭据来源和状态，不显示密钥值。
- 本地模型路径、清单和哈希属于机器运行配置，不提交源码或公共夹具。
- 能力快照是只读投影；编辑数据仍由原生工作流拥有，任务事实仍由 SQLite 账本拥有。

## 当前实现与差距

当前本地模型通过 `daelab/creative-studio/local-generation.json` 显式装配，检查 ComfyUI
节点、模型路径、哈希、Ollama 清单和 blob；文本提供方只用本地模型，不读取云密钥。现有控件可能显示不可用原因，但尚无统一的跨节点模型目录，也未按本标准
将可用性检测原因从选择界面移到日志。

权威实现边界见[本地模型装配](../architecture/LOCAL_GENERATION.md)、
[模型配置](../MODELS.md)和[提供方合同](../../backend/providers/README.md)。

## 待验收场景

1. 应用启动后，本地图片和视频模型显示真实可选或禁用状态；失败原因只进入日志。
2. Qwen 可用、Ollama 停止、清单不匹配时分别显示正确状态。
3. 已保存工作流引用已移除的 DeepSeek 模型时，显示“已保存但不可用”，保留原模型 ID，不自动换成 Qwen。
4. 服务重启和页面刷新后重建目录，生成节点与 LLM 优化节点显示一致状态。
5. 当前选择失效时保留模型身份，不自动切换，并阻止提交。
6. 不可用项不能只依赖置灰表达，键盘和读屏可取得禁用状态，但不会取得底层错误详情。
7. 检测中的圆环具有可访问名称，完成后原位替换为可选择或置灰禁用状态。
8. 模型菜单、节点和 Toast 不显示可用性检测错误。
9. 开放模型列表不会因圆环产生横向溢出。

上述场景尚未形成 F/AC/UC/TC 追踪记录；后续实施前需将其关联到现有能力目录并分配测试。
