## 方案结论与依据

展开资产库改为纵向更大的浮窗，左侧浏览目录，右侧继续预览、筛选和复用已有素材。
新建子文件夹的最短路径为：进入父目录 → 新建 → 输入名称 → 确认 → 原位看到子目录。
通过文件夹名称进入，通过面包屑或返回按钮回到父级。

会议明确要求增加纵向可见区域和新建文件夹，并提到界面建文件夹同时在本地建立目录。
会议没有确定重命名、删除、移动、共享或多选管理流程。本稿不把这些扩展当作已定需求。
参考图用于顶部工具区、文件夹图标与缩进、折叠箭头；角色/场景/物品/风格/音效仅为示例。

当前实现只读核对：asset_library.css中展开抽屉高350px、横向两边各20px；已有类型筛选、
搜索、预览、分页和加入画布。当前收藏服务与素材身份已持久化；未见文件夹创建/父子层级接口。
素材引用中的subfolder是现有文件定位字段，不能直接当作新资产库目录树。

## 面板布局建议

- 桌面默认约960×720px，最大宽高分别受视口减48px约束；相对画布底部资产库入口展开，
  保留画布周边上下文，不自动全屏。此尺寸为本稿建议，可按用户审阅调整。
- 顶部固定：资产库标题、当前服务/保存范围信息、关闭按钮。正文滚动不带走标题。
- 第二行：现有素材搜索与类型筛选，右侧“新建文件夹”主入口；不新增未定义的排序或管理操作。
- 左侧约220px目录树：资产库根、折叠箭头、文件夹图标与名称；当前目录有明确选中态，
  展开态和选中态分开。左侧单独滚动，长名称截断并可查看全名。
- 右侧：返回上一级、面包屑、当前目录名及内容区；子文件夹在素材之前，素材复用现有缩略图、
  名称、类型和预览/加入画布入口。文件夹与素材形态可辨，不用同一图片卡冒充目录。
- 搜索先保持现有“搜索收藏”的服务范围，不静默改成仅搜当前目录。搜索状态明确标注范围，
  目录导航和搜索结果分开呈现；清空后回到原目录与滚动位置。
- 窄窗口收为单列目录/内容切换，保留返回和面包屑；输入区、底部操作不出现横向溢出。
  收起面板后停止预览播放，不影响画布任务。

## 新建、进入与返回

| 情境 | 操作与反馈 |
| --- | --- |
| 根目录 | 点击“新建文件夹”，创建位置显示“资产库”；不默认批量建立参考图分类。 |
| 已进入目录 | 同一入口显示“新建子文件夹”，创建位置显示完整父路径。 |
| 输入名称 | 原位出现文件夹行与自动聚焦的名称输入框，Enter确认，Escape取消；取消不留下空目录。 |
| 校验 | 建议最多64字符；去除首尾空白，空名、同父级重名及路径分隔符拒绝并在输入处说明。不同父级可同名。 |
| 保存中 | 当前输入和确认按钮进入保存中，防重复提交；目录创建成功后才显示成功状态。 |
| 成功 | 留在父目录，新子目录可见并选中；不强迫跳入。点击名称进入，面包屑同步更新。 |
| 失败 | 保留名称和父位置，显示原因及重试；不显示已创建，不自动选择另一个父目录。 |
| 折叠箭头 | 只展开/收起树中子级；点击名称才进入目录，避免展开时意外改变当前位置。 |
| 返回 | 返回按钮回到直接父级；面包屑可跳到任意祖先；尽量恢复父级先前滚动与选中目录。 |
| 空目录 | 显示“这个文件夹还没有素材”，保留新建子文件夹和返回；不伪造上传成功或自动移动已有素材。 |

键盘可到达新建、目录行、展开箭头和返回，焦点可见；创建失败焦点保留在名称输入。
关闭后重新打开保留本次浏览位置，但目录内容必须从实际支持的数据来源读取。

## 参考版与正式保存边界

首版重点展示根目录、新建一级和二级文件夹、折叠/进入/返回、空目录及校验失败。
已有素材可以继续展示及预览。素材移动、批量归类、重命名和删除可另提方案，不做无说明的半成品入口。

若本轮只实现模拟目录，应在面板内持续显示“交互参考：演示目录，不写入本地”，
创建完成提示“已加入演示目录”，页面刷新后可能重置须提前说明。不要使用“已保存到本地”。
不要把模拟层级写进用户收藏库、工作流或真实文件路径。

正式落地须另核对受控本地根目录、目录权限、稳定folderId/parentId、同名并发、写入失败与
服务重启后恢复；这些是达成会议本地目录目标的必要技术约束，尚未在本稿实现。
现有assetId、原文件、工作流引用和收藏不因浏览目录或新建空目录改变。

## 参考验收步骤

1. 展开面板，比较现有350px抽屉：目录和素材可见区域明显增加，标题与搜索始终可见。
2. 在根新建“角色”，进入后新建“主角”；核对创建位置、树层级、成功后所在目录。
3. 用箭头折叠/展开，再点名称进入；面包屑与返回可回到根且保持定位。
4. 输入空名、同级重名和含斜线名称，核对就地错误；取消创建后无空目录。
5. 进入空目录，返回含素材目录，搜索/筛选、预览和加入画布仍按现有功能工作。
6. 小窗口、键盘和长文件夹名可操作；关闭预览不继续播放。
7. 若使用模拟数据，面板始终明确标注，不产生真实文件夹或收藏变更；不把演示完成当作正式保存通过。
