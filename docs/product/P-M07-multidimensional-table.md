# P-M07 多维表格

2026-11-02。本文件定义多维表格的产品行为。当前实现已有部分素材填充和表格输出入口；
本文件中的表内右键菜单、单格与按列菜单输出、完整素材组连接和同类型输出约束是目标
行为，不代表已经实现或完成宿主验收。

## 用户目标

- 用稳定行列组织文本、提示词、图片、视频和生成配置。
- 从画布向表格填入素材，并从单个单元格或整列生成可继续连接的素材组。
- 在生成、提示词和剪辑流程中保持行序、列类型、素材身份和编辑历史边界。

## 核心对象

| 对象 | 定义 |
| --- | --- |
| 行 | 一条创作记录，使用稳定行 ID 标识。 |
| 列 | 同一种输入或生成用途的字段，使用稳定字段 ID 和列类型。 |
| 单元格 | 行列交叉位置；文本单元格保存文本，素材单元格可保存有序素材集合。 |
| 列输出 | 将指定列中的有效单元格内容按行序处理，并按素材类型生成一个或多个素材组。 |

## 表内操作菜单

表内对象使用右键上下文的纵向菜单，不使用选中后自动出现的横向工具栏。

- 左键选择单元格、行头或列头时只更新焦点和选择，不自动打开操作菜单。
- 在单元格、行头或列头使用右键时，在指针位置打开当前对象的纵向菜单。
- 菜单选项按操作逻辑分组，组间使用分隔线。建议分组为内容与生成、填充与复制、结构与
  显示、危险操作；删除等不可逆或破坏性操作放在最后一组。
- 每个选项统一使用“图标 + 文字”形式，图标位于左侧，图标和文字左对齐并在固定行高中
  垂直居中。选项文字保持单行，不因选项内容改变行高。
- 菜单应避开指针遮挡，并根据视口边缘调整展开方向或位置，不能超出窗口或被节点内容
  裁切。
- 右键、Shift+F10 或键盘菜单键可打开当前焦点对象的菜单；方向键移动选项，Enter 执行，
  Escape 关闭并把焦点归还触发对象。

横向菜单仅用于节点级操作。例如素材组节点的标题、排列、锁定、收起、删除等操作继续
使用节点横向菜单；表格的单元格、行和列操作不使用横向菜单。

## 素材填充

- 素材拖到行头时，按顺序向右填充可编辑素材列；素材列不足时新增列。
- 素材拖到单元格时，将该次拖入的素材集合追加到当前单元格。
- 列头或列输入 Slot 接收单次快照：单个素材填满列内现有行，多个素材从第一行向下
  依次写入，行数不足时新增。
- 图片和视频素材列只接收媒体，普通文本列与提示词列只接收文本。跨类型目标不接收，
  不填入，也不形成有效连接。
- 空集合不修改表格。已有行未被本次填充覆盖的尾部内容和其他列保持原值。
- 所有填充均是一次性快照；源素材后续变化不会持续覆盖用户编辑，填充进入原生撤销历史。

## 表内内容输出

只允许以下两个输出范围：

| 范围 | 入口 | 结果 |
| --- | --- | --- |
| 单个单元格 | 单元格右键菜单 | 将当前单元格的有效内容按类型输出为一个或多个素材组。 |
| 列 | 列头右键菜单；列输出 Slot 拖出 | 将当前列的有效内容按行序处理，并按类型输出为一个或多个素材组。 |

不支持整行输出，也不支持任意多单元格选区输出。多选行、整行选择或多单元格选择不能
产生新的输出动作；这些选择仍可用于表格编辑、删除或生成范围配置。

单元格输出必须通过单元格右键菜单完成。列输出同时提供列头右键菜单和 Slot 拖出两个入口，
两条入口使用相同的输出范围、顺序和结果对象。

## 输出过滤与拆分

- 按列输出按表格行序读取单元格，单元格内部保持原有素材顺序。
- 空单元格直接跳过，不创建空占位，也不影响后续单元格的顺序。
- 失效引用直接跳过，不作为成员输出，也不阻止其他有效素材输出。
- 同一素材身份在一次输出中只保留首次出现的成员；后续重复引用去重，不改变首次出现的
  顺序。
- 输出内容按文本、图片和视频三类自动拆分，每种类型生成一个独立素材组。内容只有一类
  时生成一个组，混合类型时生成多个组，不要求用户预先筛选。
- 过滤和去重后没有任何有效成员的输出不创建素材组。

## 输出结果

- 输出的每个对象始终是素材组，不直接创建散落的单个素材节点。
- 每个拆分后的素材组只包含一种类型，并遵循 `P-M05` 的同类型约束。
- 输出完成后，表格来源与每个结果素材组之间的连线保留，不因输出结束而自动断开；保存
  和重载后仍应可识别对应来源关系。
- 输出使用一次性快照。之后编辑单元格不会自动覆盖已输出组；用户需要再次输出以创建新
  快照。
- 输出失败不得留下部分成员、孤立组或不完整连线。已有表格数据与既有输出保持不变。

## 其他明确规则

- 新建通用多维表格不默认选中前三行或多行；允许焦点落在首个单元格，但不形成默认多行选区。
- “拆出文本”复制当前文本或提示词单元格内容并创建独立文本节点，不删除原内容，也不持续
  绑定原单元格。
- 提示词批量生成只处理勾选行并保持行序。确认结果后创建一个包含各行文本节点的素材组。
- 素材组的拖入、排序、移出和快照语义由 `P-M05` 拥有；表格只决定填充目标和输出范围。
- 表格的填充与输出通过 `P-M06` 的公开连接和快照合同完成，业务模块不依赖私有 DOM。

## 当前实现与差距

现有文档已明确行头、单格、列头和 Slot 的一次性填充语义，以及“拆出文本”和提示词
批量生成结果组。现有列输出 Slot 可以物化一个素材组，但当前代码路径创建独立节点并保存
来源属性，没有建立本文件要求的持久表格到素材组连线。

现有单元格菜单没有统一的“输出为素材组”入口，列菜单也没有对应的菜单入口。当前表格
与生成结果输出还可能产生跨行分组；尚未按空值、失效引用、重复身份和素材类型完成过滤
与自动拆分，需要按本文件进一步实现和验收。

当前[前端交互规范](../architecture/FRONTEND_INTERACTION.md)记录的仍是选中对象后显示
靠近对象的横向浮动菜单。表内对象尚未统一改为右键纵向菜单，也没有固定的逻辑分组、
图标文字对齐和键盘上下文菜单行为。

## 待验收场景

1. 单元格菜单输出只包含当前单元格的有效内容，并生成一个或多个可连接的素材组。
2. 列菜单输出与列 Slot 拖出得到相同的行序、单元格内顺序、过滤和拆分结果。
3. 整行选择和多单元格选择不显示可用输出入口，也不会创建素材组。
4. 输出组与表格来源的连线在保存、重载和画布模式往返后保持。
5. 图片和视频混排的列自动生成图片组和视频组，不显示筛选步骤。
6. 空单元格、失效引用和重复素材不进入输出；重复素材保留首次出现位置。
7. 过滤后没有有效素材时不创建空素材组。
8. 输出失败时表格、已有组成员和已有连线均保持不变。
9. 后续编辑单元格不自动改写先前输出快照。
10. 左键选择单元格、行头或列头时不自动打开操作菜单。
11. 在单元格、行头或列头右键时，指针位置打开纵向菜单；选项按逻辑分组，使用左对齐的
   图标和文字，并保持固定行高。
12. 表内横向菜单不再承担单元格、行或列操作；素材组等节点级横向菜单保持可用。
13. Shift+F10 和键盘菜单键可为当前焦点对象打开菜单，方向键、Enter 和 Escape 按上述
   规则工作。
14. 靠近窗口边缘打开菜单时，菜单保持在视口内，不被节点内容裁切。

UC-BIZ-002 覆盖部分单元格媒体与填充行为，输出合同实施前需要补充对应验收和测试追踪。
