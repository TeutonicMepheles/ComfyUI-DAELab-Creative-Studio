# Creative Studio 产品模块图

2026-11-01。本文件固定 Creative Studio 的产品模块、用户目标、入口、职责、非目标和
跨模块依赖。它定义产品边界，不表示对应能力已经完成验收，也不替代现有实现合同或
[验证状态](../validation/STATUS.md)。

现有[完整功能对照表](../migration-blueprint/FEATURE_MATRIX.md)包含 118 项能力决策，
[功能用例](../migration-blueprint/USE_CASES.md)包含 41 个用户及维护者场景。本文件在
产品层将其收敛为 13 个模块。每个模块后续单独形成产品说明，并继续引用有关
F/AC/UC/TC 编号。

## 产品角色

| 角色 | 主要目标 |
| --- | --- |
| 创作者 | 从素材、文稿或分镜开始，组织内容、配置提示词、生成媒体、剪辑并交付成片。 |
| 安装与维护者 | 在隔离 ComfyUI 环境中安装、配置、诊断、迁移、升级和回滚，不修改用户既有数据。 |

角色与权限的产品细节尚未定义。当前不预设多用户账号、团队协作或审批权限。

## 模块总览

| ID | 模块 | 主要用户入口 | 核心职责 |
| --- | --- | --- | --- |
| `P-M01` | Studio 工作台与 ComfyUI 接入 | 模式菜单、空工作流、保存与打开 | 提供单一产品入口，连接 ComfyUI 原图、编辑数据和产品服务。 |
| `P-M02` | 创作画布 | 创作画布模式、空白区域和节点 | 组织、导航、选择、移动和编辑画布对象。 |
| `P-M03` | 素材与媒体 | 上传节点、文本节点、画布投放 | 承载图片、视频和文本，并执行媒体基础操作。 |
| `P-M04` | 资产库 | 画布及素材组工具栏、资产库入口 | 收藏、检索并重新使用素材。 |
| `P-M05` | 素材组 | 选区工具栏、素材组标题和组工具栏 | 将多个素材组织为可排序、可复用的集合。 |
| `P-M06` | 连接与数据交换 | Slot、连线、业务落点 | 建立类型化连接，并在模块间交换素材、文本和快照。 |
| `P-M07` | 多维表格 | 新建表格、表格节点和独立表格预览 | 编辑行列、单元格和媒体组合，承载批量创作内容。 |
| `P-M08` | 提示词与 LLM | 提示词列、单元格工具栏、文本生成节点 | 组织提示词引用、配置、优化和人工审阅。 |
| `P-M09` | 文稿与分镜 | 分镜剧本解析器、导入和转换入口 | 把文稿转换为可编辑分镜表，并保留来源与人工修改。 |
| `P-M10` | 图片与视频生成 | 生成节点、表格生成列、提示词列配置 | 把已确认的内容和参数转换为生成任务与输出素材。 |
| `P-M11` | 任务与资源管理 | 任务胶囊、生成节点状态区、恢复入口 | 展示真实任务事实，管理排队、暂停、取消、恢复和资源容量。 |
| `P-M12` | 视频剪辑与成片导出 | 剪辑节点、时间轴、成片预览 | 把有序素材编辑为单轨成片，并管理导出结果。 |
| `P-M13` | 模型与提供方管理 | 生成节点、LLM 优化节点、模型设置和健康诊断 | 发现模型与提供方，匹配产品能力，并发布可用性和绑定状态。 |

## 模块定义

### `P-M01` Studio 工作台与 ComfyUI 接入

- 术语说明：“宿主”指承载 Studio 的 ComfyUI 运行时；宿主接入是 Studio 使用 ComfyUI
  已有菜单、模式、原生图、历史、Slot 和文件生命周期的边界层。
- 用户目标：安装一个 Studio 产品包，在 ComfyUI 中切换创作画布与原图模式，打开、
  保存和重新载入工作流，并了解宿主兼容性和启动问题。
- 用户入口：ComfyUI 模式菜单、空工作流、工作流保存/打开、健康诊断和冲突报告。
- 模块职责：产品安装与注册、单一画布入口、受控的宿主桥接、构建身份、能力检查、
  保存重载生命周期和兼容诊断；宿主就绪或重连后触发 `P-M13` 刷新模型能力。
- 非目标：不拥有用户业务内容编辑规则、任务执行、模型推理或第二套工作流存储。
- 依赖关系：承载 `P-M02` 至 `P-M13`；依赖 ComfyUI 原生图、菜单、历史、Slot 和文件
  生命周期。旧包冲突必须在加载前报告。
- 规格映射：F-CAN-001/002/003/004/014/023/027/038/039；F-SYS-001/002/006/009/015/
  016/018；UC-CAN-001/013/014。
- 当前依据：[前端 ComfyUI 接入](../../frontend/src/integrations/comfyui/README.md)、
  [宿主装配](../../backend/integrations/comfyui/README.md)、
  [模块归属](../architecture/OWNERSHIP.md)。

### `P-M02` 创作画布

- 用户目标：以空间化卡片视图组织创作内容，快速浏览、定位和编辑大量节点。
- 用户入口：模式菜单、画布空白区域、节点、选区工具栏和画布导航。
- 模块职责：平移、缩放、适应视口、选择、框选、拖动、置顶、复制粘贴、删除、撤销重做、
  视口恢复以及活动、停用和旁路状态呈现。
- 非目标：不拥有表格、提示词、生成、任务或剪辑的业务状态；视角操作不形成编辑历史，
  也不能替代业务模块的编辑事务。
- 依赖关系：由 `P-M01` 提供宿主和历史；与 `P-M03`、`P-M05`、`P-M06` 共同完成内容
  组织；为 `P-M07`、`P-M10`、`P-M12` 提供画布呈现。
- 规格映射：F-CAN-008/010/011/012/013/014/027/037；F-SYS-012/013；
  UC-CAN-005/006/013。
- 当前依据：[画布模块](../../frontend/src/canvas/README.md)、
  [前端交互规范](../architecture/FRONTEND_INTERACTION.md)。

### `P-M03` 素材与媒体

- 用户目标：把本地图片、视频和文本带入作品，正确预览、替换、命名并继续消费。
- 用户入口：上传节点、独立文本节点、多文件拖入、已有素材卡片。
- 模块职责：单个和批量上传、图片/视频/文本素材、替换、标题、图片预览、视频播放、
  下载、全屏、素材身份、根目录边界和失效反馈。
- 非目标：不负责资产库筛选与收藏管理，不改变媒体原始字节，不把播放器或临时视图状态
  写入素材业务数据。
- 依赖关系：依赖 `P-M01` 的宿主文件能力；向 `P-M04` 登记资产；向 `P-M05`、
  `P-M10`、`P-M12` 提供有序、可验证的素材引用。
- 规格映射：F-CAN-005/006/007/008/009/036；UC-CAN-002/005。
- 当前依据：[素材模块](../../frontend/src/features/assets/README.md)、
  [输入资产登记合同](../architecture/ASSET_REGISTRATION.md)。

### `P-M04` 资产库

- 用户目标：保存值得复用的素材，并通过搜索、筛选、预览和分页快速找回。
- 用户入口：画布及素材组工具栏中的保存操作、资产库抽屉。
- 模块职责：素材收藏、持久资产身份、文本和文件检索、列表预览、分页和重新放入画布；
  导入和展示旧收藏的迁移结果。
- 非目标：不编辑原工作流、不保存素材组布局、不改变源文件，也不代替任务结果账本。
- 依赖关系：接收 `P-M03`、`P-M05`、`P-M10` 和 `P-M12` 产出的资产；依赖后端资产
  目录；向这些模块返回经过验证的引用。
- 规格映射：F-CAN-024/025；F-SYS-008；UC-CAN-008。
- 当前依据：[素材模块](../../frontend/src/features/assets/README.md)、
  [资产目录](../../backend/assets/README.md)。

### `P-M05` 素材组

- 用户目标：把多个素材组织为有顺序、有视觉身份、可整体处理的创作集合。
- 用户入口：多选工具栏、素材组标题、组工具栏和组输出。
- 模块职责：仅对文本、图片或视频中的同一类型素材打组；组成员移入移出、排序、水平/
  垂直/宫格排列、颜色、序号、锁定、收起、删除、整组下载和有序组快照输出。
- 非目标：不支持混合类型或嵌套素材组；不拥有成员原始文件、任务事实或下游业务配置；
  组布局不作为资产库收藏内容。
- 依赖关系：消费 `P-M03` 的素材；通过 `P-M06` 输出有序快照；向 `P-M04` 提供收藏来源，
  向 `P-M12` 提供时间轴输入。
- 规格映射：F-CAN-015/016/017/020/022；UC-CAN-003。
- 当前依据：[产品说明](P-M05-material-groups.md)、
  [素材组模块](../../frontend/src/features/groups/README.md)。

### `P-M06` 连接与数据交换

- 用户目标：用一致、可理解的方式连接节点，并把素材、文本或结果快照填入需要的位置。
- 用户入口：节点 Slot、已有连线、拖放目标、表格列/行/单元格、生成节点输入。
- 模块职责：类型化 Slot、用途选择、磁吸、连接、分支、断开、删除、关联高亮、一次性
  快照填充、组输出语义和失败反馈。
- 非目标：不自行提交生成任务，不猜测业务用途，不伪造原生连线，也不让一次性快照持续
  覆盖用户后续手工编辑。
- 依赖关系：连接 `P-M02` 的画布投影与 `P-M03`、`P-M05` 的内容；向 `P-M07` 和
  `P-M10` 交付输入；业务目标规则由接收模块拥有。
- 规格映射：F-CAN-018/019/020/021/022；F-BIZ-006/007/012/042；
  UC-CAN-004/007。
- 当前依据：[前端交互规范](../architecture/FRONTEND_INTERACTION.md)、
  [Adapter v1](../adapter-contract.md)。

### `P-M07` 多维表格

- 用户目标：用行列组织多行创作内容，在一条工作流中维护素材、文本、提示词和生成配置。
- 用户入口：新建表格、表格节点、单元格与列菜单、列输出 Slot 和独立开发预览。
- 模块职责：稳定行/列/字段身份、行列增删复制排序、选择、文本与媒体单元格、结构修改、
  列类型、列宽、隐藏列、容量限制、撤销重做、内容呈现、单格与按列素材组输出和大表行
  窗口化。
- 非目标：不提供通用电子表格公式或计算引擎；不输出整行或多单元格选区；不自行执行
  生成、优化或持久任务管理。
- 依赖关系：消费 `P-M03` 的媒体和 `P-M06` 的填充快照；通过 `P-M06` 向 `P-M05`
  输出同类型素材组；向 `P-M08` 提供同行内容，向 `P-M10` 提供勾选行和逐行配置；
  由 `P-M09` 生成分镜表。
- 规格映射：F-BIZ-001 至 F-BIZ-009、F-BIZ-041；UC-BIZ-001/002/016。
- 当前依据：[产品说明](P-M07-multidimensional-table.md)、
  [表格模块](../../frontend/src/features/table/README.md)、
  [表格工作台说明](../../dev/table/README.md)。

### `P-M08` 提示词与 LLM

- 用户目标：建立可追踪的提示词来源，复用同行内容，配置生成意图，并审阅 AI 修改。
- 用户入口：指定提示词列、单元格 `@` 引用、列配置、文本生成节点和优化面板。
- 模块职责：唯一提示词列、同行文本与媒体引用、模板和单格覆盖、最终提示词展开、
  AI 优化、文本润色、图片反推提示词、审阅与应用、模型选择及参数配置；在模型列表中
  使用 `P-M13` 发布的可用性状态；优化批次的任务暂停、打断和重启使用 `P-M11` 合同。
- 非目标：不拥有任务执行和提供方传输；不在未审阅时自动覆盖用户内容；引用展开失败
  不得静默删改。
- 依赖关系：消费 `P-M07` 的稳定行和字段、`P-M03` 的引用素材及 `P-M13` 的模型能力；
  向 `P-M10` 提供已编译输入和参数；请求事实与控制由 `P-M11` 管理；分镜可复用提示词
  编辑能力。
- 规格映射：F-BIZ-010 至 F-BIZ-017、F-BIZ-043；UC-BIZ-005/006/007/008。
- 当前依据：[提示词模块](../../frontend/src/features/prompt/README.md)、
  [提示词服务](../../backend/prompt/README.md)。

### `P-M09` 文稿与分镜

- 用户目标：从 Word 分镜文稿建立可编辑表格，保留来源、章节、图片顺序和人工修订。
- 用户入口：分镜剧本解析器、上传/追加/替换文档、导入详情和旧表转换入口。
- 模块职责：DOCX 解析、分镜字段识别、镜号/画面描述/画面参考/备注四列投影、章节分组、
  每表最多 10 行、去重追加、修订合并、图片归属、来源追踪和可选 AI 归类。
- 非目标：首版不解析任意文案并自动拆镜；不在用户未确认时覆盖原分镜；生成图片或视频
  不属于导入模块。
- 依赖关系：依赖 `P-M07` 提供编辑容器和 `P-M08` 提供画面描述编辑器；向 `P-M10` 提供
  分镜任务内容；图片通过 `P-M03` 进入素材体系。
- 规格映射：F-BIZ-018 至 F-BIZ-022、F-BIZ-044；UC-BIZ-003/004/008。
- 当前依据：[分镜模块](../../frontend/src/features/storyboard/README.md)、
  [分镜服务](../../backend/storyboard/README.md)。

### `P-M10` 图片与视频生成

- 用户目标：从表格行、提示词或已连接素材建立图片/视频生成任务，并在完成后继续创作。
- 用户入口：生成节点、表格生成列、提示词列模型配置、输出占位和素材组输出。
- 模块职责：收集文字/图片/视频输入，从 `P-M13` 读取模型能力，配置模式与参数，冻结
  提交输入，创建单个或批量任务，选择抽卡次数，生成结果占位、回填、历史预览和素材组
  输出；单任务节点显示真实百分比，成组任务的节点左上角只显示总任务数和已完成数；
  在模型列表中使用可用性状态；任务动作和状态转换委托 `P-M11`。
- 非目标：不拥有持久任务事实或宿主执行队列；不自动替换模型、不补充模型未声明的模式，
  不因取消前端请求而伪造 provider 已停止。
- 依赖关系：消费 `P-M03`、`P-M05`、`P-M06`、`P-M07`、`P-M08` 和 `P-M13`；通过
  `P-M11` 提交并观察任务；结果登记到 `P-M03`/`P-M04`。
- 规格映射：F-BIZ-023 至 F-BIZ-036、F-BIZ-042；UC-BIZ-009/010/013/014。
- 当前依据：[生成模块](../../frontend/src/features/generation/README.md)、
  [生成服务](../../backend/generation/README.md)、
  [提供方合同](../../backend/providers/README.md)。

### `P-M11` 任务与资源管理

- 用户目标：知道任务是否排队、运行、完成、失败或状态未知，并能对单个任务或明确范围
  安全执行暂停、打断、继续、重启和恢复。
- 用户入口：任务胶囊、生成节点任务状态区、结果恢复和取消确认。
- 模块职责：持久任务账本、任务状态投影、真实进度和等待时间、恢复原请求、结果完整性、
  单任务真实百分比进度、暂停与继续、打断与确认、显式重启、资源准入和并发限制。
- 非目标：不拥有工作流撤销历史，不替代 provider 执行，不用估算百分比代替真实状态，
  不允许撤销操作改写持久任务事实。
- 依赖关系：接收 `P-M08`、`P-M10` 和 `P-M12` 的任务；向 `P-M03` 提供经验证结果；
  资源容量跨本地 GPU、云端提供方协议和转码任务；从 `P-M13` 获取提供方控制能力，但不把
  它当作分布式全局调度。
- 规格映射：F-CAN-026；F-BIZ-029 至 F-BIZ-035；F-SYS-007/010/019；
  UC-CAN-009、UC-BIZ-011/012/013/014、UC-SYS-004/008。
- 当前依据：[生成任务控制产品说明](P-M11-generation-task-control.md)、
  [单任务进度产品说明](P-M11-generation-task-progress.md)、
  [任务展示](../../frontend/src/features/tasks/README.md)、
  [任务账本](../../backend/jobs/README.md)、
  [编辑事务与异步结果](../architecture/EDITING.md)。

### `P-M12` 视频剪辑与成片导出

- 用户目标：把一组有序图片、视频和音频编辑为可预览、可下载并继续消费的成片。
- 用户入口：剪辑节点、时间轴、片段菜单、预览和导出区。
- 模块职责：素材组到单轨时间轴的同步与去重、片段排序、裁剪、分割、删除、吸附、逐帧
  操作、播放预览、画幅/分辨率、画面适配、静音、导出进度、取消和结果失效。
- 非目标：当前不定义多轨合成、任意转场/特效时间线或复杂 NLE 能力；编辑后的旧成片不能
  继续作为当前结果使用。
- 依赖关系：消费 `P-M03` 和 `P-M05`，通过 `P-M06` 接入素材组；导出任务由 `P-M11` 管理；
  成片登记为可继续引用的素材。
- 规格映射：F-CAN-028 至 F-CAN-034；UC-CAN-010/011/012。
- 当前依据：[剪辑模块](../../frontend/src/features/editor/README.md)、
  [媒体导出服务](../../backend/media/README.md)、
  [导出合同](../../backend/media/EXPORT_CONTRACT.md)。

### `P-M13` 模型与提供方管理

- 用户目标：打开服务或应用后，模型列表准确反映本机当前可用的本地模型和已配置的
  DeepSeek API，并在服务重启、配置变化或页面刷新后恢复正确状态。
- 用户入口：生成节点、LLM 优化节点、多维表格模型配置、健康诊断和手动重新检测。
- 模块职责：发现模型与提供方、匹配产品能力、维护逻辑模型身份和运行时绑定、发布
  可用性状态、查询/取消/作用域内中断及进度能力、清理过期能力快照；为 `P-M08` 和
  `P-M10` 提供同一模型目录，为 `P-M11` 提供提供方控制与进度能力。
- 非目标：不执行推理、不排队或占用 GPU、不保存工作流编辑数据、不下载模型、不启动
  Ollama、不静默替换模型，也不将 DeepSeek 密钥写入工作流或任务账本。
- 依赖关系：由 `P-M01` 在宿主就绪或重连后触发，并由 `P-M11` 在执行时提供资源状态；
  为 `P-M08` 和 `P-M10` 发布模型能力与可用性状态。
- 规格映射：F-BIZ-016/025/026/027/028/030/031/032；F-SYS-006/009/011；
  UC-BIZ-006/007/009/010、UC-SYS-007/009。
- 当前依据：[产品说明](P-M13-model-provider-management.md)、
  [模型配置](../MODELS.md)、[本地模型装配](../architecture/LOCAL_GENERATION.md)、
  [提供方合同](../../backend/providers/README.md)。

## 主创作链路

```text
P-M01 工作台
  -> P-M02 创作画布
  -> P-M03 素材 / P-M05 素材组
  -> P-M07 表格 / P-M09 分镜 / P-M08 提示词
  -> P-M06 连接与快照交换
  -> P-M10 生成
  -> P-M11 任务与结果
  -> P-M04 资产库 / P-M12 剪辑与导出

P-M01 工作台 -> P-M13 模型与提供方 -> P-M08 提示词与 LLM / P-M10 生成
```

这不是唯一使用顺序。表格可直接编辑，分镜可独立导入，生成也可由独立节点发起；主链路
用于约束模块交接和端到端产品验收。

## 跨模块规则

- 原生工作流拥有编辑数据；`P-M11` 的 SQLite 账本拥有任务事实；资产目录拥有可验证的
  资产身份；聚焦、悬停、播放位置等瞬时状态由当前视图会话拥有。
- 模块通过公开 adapter、端口和快照交换，不读取另一模块的私有 DOM 或重复保存其状态。
- 生成节点、LLM 优化节点和多维表格必须使用 `P-M13` 的同一可用性状态。模型列表中的
  可用、检测中和不可用呈现由状态语义驱动，业务面板不得自行猜测模型是否可用。
- 兼容读取必须保留未知原始数据和可见报告，不能让旧实现与新实现同时注册。
- ComfyTV 仅为可选只读上游，不打包、不修改其源码。
- 徽章、展厅、分割工具、旧 LibTV 执行通道和原型面板不属于上述 13 个产品模块。
- 稳定节点 ID、原生 Slot 索引、material JSON、`daelabCreativeCanvasV1`、剪贴板和
  adapter v1 属于产品兼容边界。权威合同见[前端交互](../architecture/FRONTEND_INTERACTION.md)、
  [编辑事务](../architecture/EDITING.md)、[任务与资产](../architecture/JOBS_ASSETS.md)、
  [Adapter v1](../adapter-contract.md)和[任务合同](../task-contract.md)。
