## 二、层级定义（固定六档，不再新增）

| 层级 | 字号 / 字重 | 使用位置 |
| --- | --- | --- |
| T1 页面级 | 20 / 600 | 仅工作台级标题、空画布大标题（极少数） |
| T2 标题级 | 15 / 600 | 节点标题、面板头部、**弹层标题**、空态主文案 |
| T3 控件级 | 14 / 400–500 | 按钮、**菜单选项**、字段名、页签、表格表头与单元格、输入框文字 |
| T4 正文级 | 13 / 400 | 多行正文、提示词内容、说明段落（不用于控件标签） |
| T5 辅助级 | 12 / 400–500 | 计数、单位、时间、次要标注、**菜单分组标签（12/500）** |
| T6 徽章级 | 11 / 500 | 胶囊、徽章、极限标注；**11px 为下限** |

层级顺序固定：T1 > T2 > T3 > T4 > T5 > T6。

## 四、规则（优先级高于具体数值）

1. **单一档位**：同一控件族（按钮、菜单选项、字段、胶囊…）只取一个层级，不因所在页面而变化。
2. **禁止倒置**：子元素不得大于父级的同级文字；浮层标题 ≤ 所属面板标题；分组标签不得大于选项文字。
3. **字重收敛**：只用 400 / 500 / 600；不使用 700 与 `inherit` 混用。
4. **禁止覆盖**：不对 `font-size` / `font-weight` 使用 `!important`；出现覆盖应回到主题层解决。
5. **字号只出现在主题层**：允许在 `frontend/src/design/creative_theme.css` 与 `ui/studio_theme`、`ui/table_workbench_theme` 定义；**不在 `.mjs` 内联样式里写死字号**（现有 35 处需迁出，路径以 `frontend/src` 为准，`web/` 为构建产物不单独改）。
6. **图标不用字号**：图标尺寸用 `width`/`height`，禁止用 `font-size` 放大符号（现有「取消」按钮 22px 属此类）。
7. **隐藏不用字号**：不使用 `font-size:0` 作隐藏手段（现有 4 处），改用 `display:none` 或 `visibility`。
8. **可读性下限**：任何可见中文 ≥ 11px；表格行内文字 ≥ 12px。
9. **缩放不改变层级**：画布缩放只整体缩放（沿用 AC-CAN-023-005），不改变文字相对大小。
