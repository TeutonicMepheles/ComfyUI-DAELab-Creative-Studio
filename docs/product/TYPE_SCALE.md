## 三、待评审建议（尚未同意，不得当作违规判定）

- 是否保留「页面级 20/600」这一档（仅工作台级/空画布标题使用）。
- 同族单档原则：同一控件族只取一个档位，不因页面而变化。
- 父子字号差异按角色判断：只有**同一角色**出现不同档位才算不一致；不做「父子字号不同即为倒置」的推论。浮层标题不高于所属面板标题这一点同样以角色一致为准。
- 字重收敛为 400 / 500 / 600（是否禁用 700 待定）。
- 是否禁止对 `font-size` / `font-weight` 使用 `!important`（改为回主题层解决）。
- 字号只在主题层定义，脚本内联的 31 处是否迁出。
- 表格表头与单元格是否统一为 14（同一行必须一致这一点应先确认）。
- 图标尺寸使用 `width`/`height`，不以 `font-size` 放大符号。
- 隐藏使用 `display:none` / `visibility`，不以 `font-size:0` 代替。
- 可见文字下限 11px、表格行内不低于 12px。
- 画布缩放只整体缩放，不改变文字相对层级（沿用 AC-CAN-023-005）。
