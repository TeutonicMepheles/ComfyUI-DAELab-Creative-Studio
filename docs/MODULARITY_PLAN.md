# 模块解耦与 README 实施计划

日期：2026-10-27。状态：实施中。代码观察基线：`963cb6a`。

本计划以表格为试点，建立公共接口、独立预览、依赖检查和模块文档，再推广到提示词、剪辑和生成配置。本次交付仅为计划和文档规则，不代表代码解耦或产品验收完成。

## 1. 目标与边界

保留单仓库、单安装包。模块应能分别修改、测试和预览；本阶段不要求独立发布或部署每个模块。

延续现有合同：原生工作流保存编辑数据，SQLite 保存任务事实；撤销不修改任务事实。保留节点 ID、Slot 索引、material JSON、`daelabCreativeCanvasV1`、剪贴板和公开 adapter v1。生产环境继续使用 ComfyUI 原生执行队列。

复用现有 ESM、严格 TypeScript 接口和共享控件。不更换 UI 框架，不引入新的生成服务，不复制 ComfyTV 源码。试点不改变表格默认列、初始三行、500 行与 64 列上限。独立预览不进入产品构建或节点注册。

## 3. 表格目标边界

| 部分 | 拥有内容 | 外部交互 |
| --- | --- | --- |
| 表格核心 | 行列、单元格、选择规则、结构操作、序列化验证 | 数据和明确的扩展合同 |
| 表格视图 | 渲染、输入、焦点、菜单、实例生命周期 | 核心、共享 UI、注入端口 |
| 功能扩展 | 提示词列、生成列的识别、验证、呈现和操作 | 通过明确扩展接口接入 |
| application | 表格与提示词、生成、素材服务的组合 | 各模块公共入口 |
| integrations/comfyui | 节点、原生历史、Slot、保存与模式接入 | 实现模块所需宿主端口 |
| 独立预览 | 内存文档、合成素材、可控服务状态 | 装配同一套生产模块 |

拟新增 `frontend/src/features/table/index.ts` 和 `contracts.ts`。先定义公共入口与能力边界，再按需要拆出核心和视图；不为统一目录形式批量搬文件。

复用 `NativeDocumentPort` 和现有资产、任务合同。新接口只补缺失能力，不定义第二套可写文档或任务账本。将画布面板、上传、通知、确认、列扩展等依赖显式传入；按能力拆小接口，不建立包揽所有服务的全局对象。

生产装配保留全部现有列能力。基础预览允许关闭生成或优化服务，但须保留已保存字段及未知合法数据，显示不可用原因，不产生虚假成功或静默丢弃配置。状态、监听器、取消控制器和释放逻辑按实例管理。

## 4. 实施批次

每批独立提交、经审核与当前提交检查后合并。前一批达到出口条件，再进入依赖它的下一批。

| 批次 | 改动范围与交付物 | 出口条件 |
| --- | --- | --- |
| T0 依赖基线 | 盘点 table 的导入、调用方、全局访问、数据格式和现有测试；记录依赖表及可复现失败 | 公共入口候选、兼容夹具和验收用例明确；执行相关原有测试并保留结果 |
| T1 公共边界 | 新增 table 公共入口与类型；复用文档端口；将跨功能组合归入 application；通用控件回到 ui | 调用方通过公共入口；基础表格不直接引用 prompt/generation 内部实现；定向测试通过 |
| T2 能力与状态隔离 | 注入面板、素材和通知等能力；隔离视图状态；实现卸载清理；保留旧入口薄包装至调用方迁完 | 无隐含全局宿主依赖；两个实例互不干扰；迟到结果和卸载回调不能改写其他文档 |
| T3 独立预览 | 增加 `dev/table/`、双实例页面和浏览器检查；最小本地服务提供合成 `/view` 素材；接入 package scripts | 无 ComfyUI/GPU 时真实编辑器可运行；基础模式和完整扩展模拟模式均可检查；构建不打包预览 |
| T4 防回退与宿主验收 | 扩展架构规则及针对性测试；核对候选包；在独立 ComfyUI 中验证集成 | 本计划验收矩阵通过，或明确保留失败并不宣称试点完成 |
| D1 文档整理 | 根 README、安装与功能指南、表格和相邻模块 README、开发指南及导航 | 使用者能安装并打开示例；开发者可按真实命令启动试点与定位测试；链接和生成副本一致 |

D1 的安装和文风整理可与 T0 并行推进；独立开发说明须等 T3 命令实际可用后更新。T0 为新用例关联既有 F/AC/UC/TC/EV；缺项从拥有 JSON 补充并生成视图，不直接修改生成目录。

T1/T2 的旧入口包装只负责兼容转发，不保留第二套实现。每批保留可回退提交；若合同检查失败，回退该批代码，不转换用户数据或删除历史字段。

## 5. 独立开发入口

以下为拟议命令，尚未实现，不可作为当前使用说明：

```text
npm run dev:table       启动本地表格预览
npm run test:table      核心、合同与扩展集成测试
npm run test:table:ui   浏览器交互测试
```

预览页面至少包含：双实例、空表与标准表、素材列、提示词列、生成列，以及加载、错误、不可用和卸载场景。测试服务不连接模型、不提交真实任务；模拟任务显式标识。内存历史仅用于预览，生产适配仍调用原生历史。

优先使用现有构建产物及轻量开发服务器，按需添加浏览器测试依赖。新工具需写明启动、停止、端口、数据位置和错误诊断；不要求为了预览安装 Vue 或改写现有 UI。

## 6. 验收矩阵

| 范围 | 必须验证 | 证据 |
| --- | --- | --- |
| 核心与兼容 | 行列 ID、未知字段、默认列、容量上限、素材顺序、序列化往返、剪贴板、撤销重做 | 固定夹具与定向测试 |
| 依赖边界 | 禁止跨功能内部导入、宿主反向依赖和新循环；允许明确公共入口；规则能识别故意违规样例 | 架构检查及其回归测试 |
| 双实例 | 焦点、选择、菜单、撤销、上传、迟到结果、卸载重挂互不串扰 | 浏览器用例与结果 |
| 可选能力 | 无模型时仍可编辑；生成/优化不可用原因明确；既有配置不丢失 | 基础与扩展模式用例 |
| 真实 ComfyUI | 两实例、溢出/焦点、Active/Mute/Bypass、模式切换、保存重开、相关缩放与窄视口、Slot 和素材交换 | 环境、提交、操作与结果记录 |
| 安装与集成 | Studio 独立安装；可选 ComfyTV 组合安装只读接入；旧 Canvas/业务包冲突仍被拒绝 | 启动与功能检查记录 |
| 性能 | 同一夹具比较编辑、保存、撤销；记录 100 ms 预算的实际结果 | 测量条件与原始结果；既有失败不重写 |
| 打包与文档 | 预览/测试代码未进入产品；README 命令、链接和生成副本有效 | 构建、候选包及文档检查 |

真实任务恢复只在确需验证且已有许可的本地模型条件下执行；不以付费生成验证重构。浏览器模拟、构建通过和 CPU 测试不能代替真实宿主或 GPU 验收。某项缺少条件时记为未执行，不能据此关闭试点或 M6。

现有检查入口：表格 README 中的定向命令、`npm run check`、候选包测试及 `.github/workflows/checks.yml`。实现时按改动范围运行，PR 完成要求的当前提交检查；纯计划改动仅做文档检查。

## 7. README 整理范围

全部第一方文档遵循 [写作规范](WRITING.md)。先整理入口，再按功能推进；不一次性重写所有目录。

| 范围 | 整理内容 |
| --- | --- |
| 根 README | 产品用途、开发版状态、无旧仓库安装、首次进入画布、Showcase、模型前提和开发导航 |
| docs | 安装、使用、模型配置、排错入口；保留当前合同、目标规格与验证证据的区别 |
| frontend、backend、compat | 子模块职责、依赖方向、公共合同与定位导航 |
| table 及关联 prompt/generation/application/integrations | 接口、能力、数据归属、独立预览、定向测试及宿主验收 |
| assets/groups/storyboard/tasks/editor | 按试点模板逐模块整理；未提供独立入口时明确注明 |
| tests、tools、dev | 运行前提、命令、输入输出、副作用与证据限制 |
| Showcase、资源目录 | 通用使用步骤、素材来源；本机安装状态与历史结果链接到验证记录 |
| web 与目录生成视图 | 从拥有源生成，不独立编辑 |

新增指南应先确认现有文档是否已经拥有该内容，避免重复建立权威来源。模型指南核对实际配置字段，不复制本机路径。架构规范中的旧仓库路径按当前源码核实更新，并保留历史适用范围。

第三方文档保留原文；历史失败保留原记录。`tools/migration/legacy_probe/README.md` 属于固定包身份，仅在必要时按其 AGENTS 同步清单和固定值，不为统一文风单独改写。

## 8. 完成与推广

表格试点完成需同时满足：公共入口稳定、依赖检查生效、独立预览可复现、定向测试通过、真实宿主验收完成、文档与实现一致。记录实际提交、环境、失败和未覆盖项，不将试点完成视为 M6 通过。
