## 本地模型（图片/视频）实测口径

本轮“按清单在本机配置所有模型并在画布跑通”属于用户明确要求，不能用原生组件验证或界面检查替代画布实测。

**图片（基础 Qwen，已验收）**：构建 `f9dbb1b` 之后的独立 profile 构建 `195aaee`／合并 `d9ea790`；模型来源为本地，原生 CLIPLoader、25 步、非 Turbo；单次出图与表格两行各一次成功（三笔请求各执行一次），两行原生计时约 11.56 / 13.23 秒、整轮约 26.94 秒，显存峰值约 14902 MiB。报告 `gap-review/BASE_QWEN_REVIEW_20261105.md`。默认仍为 Turbo，基础版独立可选。

**视频（MiniMax FL 及后续 Ref）必须在画布上实测，才算通过**：

1. 图片/视频节点内能看到该本地视频模型作为独立选项，来源胶囊为本地；默认值未被替换，旧模型选择与旧请求不被改写。
2. **节点单次生成**：选定本地 FL，真实提交一次，结果回填到节点并可预览；记录请求身份、分辨率、整数秒时长、步数、原生执行耗时与显存峰值。
3. **表格两行队列**：接入表格、勾选两行后显示“共 N 个任务”，串行各出一次结果并回填到对应行；提示词与参考素材顺序按行保持，不串行、不合并。
4. 参考素材（首帧/多图参考）身份与顺序需在冻结输入中与界面选择一致。
5. 组件缺失或哈希不符时在画布内报“不可用 + 原因”，不静默回退 Turbo 或其它模型。
6. 原生组件验证（如 FL int8 与视频 VAE 的加载/出片）只作前置证据，不能单独作为本项通过依据。

未完成上述 1–5 之前，视频侧不得记为本轮通过，也不得以“选项可见、来源正确、缺组件报错”这类界面检查收口。
