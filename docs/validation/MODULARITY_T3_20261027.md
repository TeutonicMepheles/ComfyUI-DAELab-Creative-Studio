# 表格独立预览记录

日期：2026-10-27。T3 提供真实生产编辑器的无 ComfyUI 装配；不代表宿主、模型或性能验收。

`npm run dev:table` 启动本地只读静态服务和合成 `/view` 素材。页面使用生产表格、提示词与生成设置模块，两个实例各自持有内存文档和历史，显式共享结构剪贴板。基础模式保留生成配置并显示不可用原因；完整模式只绑定模拟服务。服务状态可选正常、延迟、错误或不可用。

Windows 已安装 Chrome、1440×1000 和 600×800 视口：`npm run test:table:ui` 的 5 项浏览器用例通过。覆盖双实例编辑、内存保存重载及未知字段、侧栏卸载、迟到生成与上传、窄视口内部滚动、模拟结果回填、撤销和结构剪贴板。`npm run test:table` 的 38 项定向用例通过。

首次浏览器失败是用例错误地查找 dialog；实际拥有组件为非模态侧栏。第二次失败是用例假定重开侧栏自动重试；实际须点击“重新读取模型选项”。两个原始失败及截图/trace 保留在 `.local/modularity/T3-browser-first*`、`T3-browser-second*`。最终日志为 `T3-browser-final.log`，定向日志为 `T3-table.log`。

`dev/` 位于前端构建输入以外，隔离宿主快照也显式排除它。候选包由 T4 再核对。浏览器测试加入 CI，使用独立 Chromium，不连接模型。真实 ComfyUI 的模式/保存/Slot、可选 ComfyTV 和 100 ms 输入预算仍由 T4 记录。
