# 图片视频节点布局源码检查

候选分支 `codex/compact-generation-panels`，基线 `091fafe`。用户三图对应内容卡边界、模型列表样式及新建外框比例；产品确认新建独立图片/视频默认 5:4，菜单始终向上，保留旧尺寸与输出参数。

实现将固定类型媒体面板的外层 padding 归零、隐藏无操作标题行并去掉重复边框。既有画布框承担选择与缩放边界。新建默认比例仅在适配器中调整，不回写已保存卡片或模型尺寸。生成参数、模型、提示词来源及整列设置显式使用向上定位，限制在触发项上方空间并内部滚动。模型列表复用触发项实际显示字号、字重、图标盒及图标中心线；来源元数据决定青绿/蓝紫，不依赖模型名猜测。

执行的源码检查：

- TypeScript、198 模块架构检查、676 项业务测试通过；其他前端 448 项通过、3 项既有跳过。
- 几何回归覆盖向上限高、图标对齐和视口右边缘夹取；实际适配器回归覆盖新建 5:4、旧 777×333 卡片和输出参数保留。
- Chromium `--disable-gpu` 加载实际 `installVideoTasks` 和实际模型菜单，使用两个独立节点及合成空任务服务；未提交生成。面板与画布 body padding 为 0，内层 border 为 0；空标题隐藏，内容卡距离框边为 1px。
- 普通/80% 缩放下，列表与触发项图标分别为 18/18px、14.40/14.39px，字号分别为 14/14px、11.20/11.20px；图标中心误差不超过 0.02px。两种来源保留文字与不同颜色。
- 上边缘场景菜单 top=8px、底部仍距触发项 8px，菜单限高 195px 且可滚动至最后一项，没有翻到下方。

首轮业务测试暴露旧 DOM 测试替身未实现 `classList.contains` 与模型图标查询；已将图标逻辑限于模型菜单，并补充替身的标准 classList 行为，原优化菜单 14 项定向回归通过。原始结果与截图位于工作树 `.local-compact-*`，不进入运行包。
