执行任务的唯一机器入口为 catalog/traceability.json；任务按阶段与负责模块合并。
各项验收要求的 AC 固定在权威 catalog 功能记录，不能因文案重排重编号。

```sh
node tools/evals/traceability.mjs --select --phase M1
node tools/evals/traceability.mjs --gate --phase M1 --fingerprint .local/current-fingerprint.json --evidence-dir .local/evidence
```

没有正式逐TC有效证据时 gate 必须阻塞。本地原始证据和首次失败留在 .local；
公开报告只引用脱敏信息。源码变更后旧宿主快照继续保留，但其检查结果不得
自动转移到新的构建。完整本地模型批次报告必须满足 local-batch.schema.json。
