# 表格边界与宿主验收

日期：2026-10-27。实现与防回退检查已执行；表格试点验收未关闭，M6 未通过。

## 边界与回归

表格公开入口限定为 `index.ts`、`contracts.ts`、`core_model.mjs`、`view.ts` 和 `public_helpers.mjs`。内部实现不得导入其他功能或 application 的运行代码；历史路径只能转发，生产调用方不得继续依赖这些包装。类型引用复用既有文档端口。相邻功能尚未推广同一封闭边界，不能将表格规则宣称为全仓模块解耦。

故意违规夹具覆盖私有导入、旧包装消费、宿主全局、反向装配、包装内隐藏逻辑、层级与循环。首次规则测试发现跨功能前缀的匹配遗漏，修正后 `npm run check` 通过：174 模块，主套件 367 通过/3 个既有跳过，业务 515 通过。独立浏览器 5 项通过；候选包合同 9 项、冲突检测 3 项、可选宿主工具 7 项通过。首失败保留在 `.local/modularity/T4-check-first.log`。

## 性能与未覆盖项

对固定 `FX-PERF-L-no-video.json` 的同一 500×10 表，Node 模型阶段比较 `963cb6a` 与 T4，各预热 5 次、采集 30 次。编辑复制/序列化/撤销规范化 p95 分别为基线 1.21/0.67/3.43 ms，T4 1.33/0.68/4.35 ms。原样本与夹具 SHA256 位于 `T4-model-performance.json`。这些阶段不包含浏览器绘制、宿主保存和原生历史，不能判定 100 ms 端到端预算通过，也不作性能收益声明。

100 ms 既有失败、真实 IME、完整拖放与所有缩放矩阵仍未关闭；18% 列设置命中失败已明确保留。本批满足计划“保留失败、不宣称试点完成”的出口，后续模块推广与正式发布仍不能据此通过。
