### 1. 文本生成输入与结果编辑

未连接时，文本生成节点保留可编辑的本地草稿。连接外部文本后输入区只读并置灰，不写回上游；断开连接后恢复原草稿。表格消费仍只读取指定提示词列与勾选行。

生成结果进入现有审阅流程。修改后的结果需要人工执行“应用”或输出；输入、工作流或会话变化后，旧结果仍可查看，但不能再次应用。实际应用通过现有文档事务写入原生历史。

### 2. 提示词引用正确性

列模板按稳定行 ID 和字段 ID 展开，不依赖当前数组位置。重排行、更新引用字段和设置单格覆盖后，预览与生成请求继续使用同一解析结果。只有指定提示词列允许引用其他文本列，备注仅在明确引用时参与。

缺失字段、非法引用和循环引用继续抛出可见错误。本轮没有更改模板结构或首尾帧配置。

### 3. 素材同步与删除

持续连接和一次性拖入保持不同语义。重连替换同一来源的注入快照，断连只清理该来源注入的内容；没有可靠来源标记的旧内容不批量清除。直接拖入单元格追加素材，不伪装为持久连线。

素材删除按素材身份执行，不按位置或文件名删除。订单、引用和无关手动素材保持不变，删除与恢复使用原生历史，不删除磁盘文件。

### 4. 文本单元格拆出与填充

文本单元格可拆成已有类型的独立文本节点。拆出复制当前展开文本并保留换行，不删除原单元格，也不建立持续绑定；展开失败时阻止拆出并显示原因。

文本组按顺序填行，单文本可整列填充。输入不足时不循环复用；超过目标容量时明确提示，不静默截断。

### 5. 批量范围与状态

待提交范围随勾选变化。提交时冻结稳定行身份、输入摘要和请求身份，之后取消勾选或修改表格不删除、不改写已提交任务。批量总上限沿用现有规则。

单任务抽卡限制为 1–4 次；0 和 5 在提交前拒绝。界面区分排队、生成中、完成、失败、取消和未知状态，不伪造百分比。未知任务先查询原请求身份，不自动重提。

本轮只完成受控模拟和自动测试。隔离宿主缺少所需本地模型节点与固定指纹的一个 H3 VAE，因此没有执行真实 provider 提交、完成后回填或真实未知状态恢复。

### 6. 命名、默认值与重复控件

界面统一使用“文本生成”“Comfy”“全能参考”。只修改显示名称，节点类型和序列化键不变。新配置根据模型能力采用中等图片质量与合法整数视频秒数；旧工作流已保存参数不被覆盖，模型不支持的选项不写入。

表格已有指定提示词列时，生成端不再重复显示来源选择。列默认配置保留抽卡入口；任务缩略区、列内生成能力和现有模型列表未移除。

### 7. 画布基础交互

画布空白拖动、复制、粘贴和删除快捷键在有活动文本选区时让出所有权；输入法组合输入继续由编辑器拥有。同类型文件多选、组/单素材选择态、连接失败或取消后的临时线和高亮沿用共享控件规则。

接口命中先修正画布投影与缩放换算，保留 32 屏幕像素基线。自动测试覆盖 50%、100%、150% 缩放及高节点端口；隔离宿主检查 Active、Mute、Bypass 与 51%、100%、156% 显示缩放。

### 8. 剪辑素材去重

剪辑素材列表按现有素材身份和 SHA-256 指纹去重。同名但内容不同的素材保留；同一素材改名或从相同来源重连时不追加第二条列表项。

去重不合并时间线上用户主动复制的片段。片段顺序、源范围、时长和导出编码策略未改变。
