# 解析表列头视觉回归

范围：task #14 / AC-BIZ-020-003。用户标注的列头圆形加号、重复按钮及更多菜单偏移。

## 根因与修复

解析表复用了普通表的列输出 Slot、增列和提示词来源切换控件；四列解析表的固定
结构不支持这些操作，列输出与提示词按钮共用右侧定位，出现重叠。
原生基线实测：四个列输出按钮、一个新增列按钮、三个提示词切换按钮；更多按钮
也与全选框重叠。

共享编辑器新增可选 `columnControls`，共享呈现新增可选 `columnOutputs`，默认均
保留普通表行为。解析表显式关闭这些控件，保留已有提示词标记、导入问题提示与
新增行；更多菜单在原行号区域独立定位。没有变更解析结果、字段身份、来源或节点类型。

## 验证范围

- 在真实 8365、2048×1185 独立浏览器会话中，旧版探针先失败：列输出 4、增列 1。
- 浏览器仅替换本次源码响应后，列输出、增列、提示词切换均为 0，提示词标记保留 1。
- 50%、75%、100%、150% 画布缩放下更多菜单与全选框不重叠。
- 合成待分配图片触发原有问题提示；原位编辑、原生撤销/重做、保存重载与来源保留通过。
- 同会话普通表保留列输出、增列和提示词切换，浏览器无异常。
- Business 635 项、严格类型检查、189 模块架构检查通过。

原始探针、前后截图和 JSON 保存在 Implementer 工作区 `parser-style-check.mjs` 与
`parser-style-before/after.*`。浏览器响应替换仅用于实现阶段复现，不等于测试服已更新。
最终构建仍须由 Controller 检查，Reviewer 在 8365 独立同视口截图并回归编辑和重载。
