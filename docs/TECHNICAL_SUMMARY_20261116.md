# 工作流修复与模型配置技术总结

本报告记录 11 月 13 日会议后与工作流稳定性相关的实现和文档状态。2026-11-16 用户将本阶段重心定为 Bug 修复与文档完整；附加风格噪点、VAE/解码检查和中文文字清晰度对比暂缓，不作为本阶段收尾条件。任务登记及本轮证据见 [当前记录](validation/WORKFLOW_BUGS_20261116.md)。

## 模块与数据归属

Studio 单包拥有画布、表格、提示词、生成与任务。画布通过公开 adapter v1 消费能力；业务面板不另设 Slot 手势。原生工作流保存编辑数据、稳定节点及槽位身份；SQLite 保存任务事实。旧展厅、徽章、分割节点由旧业务库维护，不因本轮修复迁入 Studio。

## 已有成果与本轮改动

- 素材栏上传“＋”固定在首位，上传、删除及重开后仍可追加，沿用原上传和素材事务。历史证据见 [11 月 13 日记录](validation/MATERIAL_ADD_PERSISTENCE_20261113.md)，图片与视频补验见当前记录。
- 剧本按 DOCX 独立源表创建 `DAELAB.Table`，批量提交、身份及失败回滚由原文档控制器负责。本轮只令空解析器声明不可新建输出，隐藏无效入口；旧解析器有记录时仍可输出。已保存槽位与连线不删除。
- 文字选区由画布持有时，点击其他控件清理旧选区。同一编辑器内操作与画布外选区保留；沿用共享导航与现有拖动边界，不改变文本内容或工作流数据。
- 文本输入可连接图片、视频、文本生成；文本生成输出仍走既有结果输出合同。两种节点的规则不混用。
- 模型提示词改写已有四个模板和审阅流程，历史验证使用明确替身，不证明真实模型质量；见 [改写记录](validation/PROMPT_REWRITE_20261113.md)。

## 模型配置现状

2026-11-16 补充：[18 项模型接入配置表](MODEL_ACCESS_CONFIGURATION_20261116.md)和 [CSV](MODEL_ACCESS_CONFIGURATION_20261116.csv)已按 `47e597d` 源码整理，字段待补与能力待开发分别登记；文档交付不表示统一配置机制已开发完成。

共享逻辑模型目录覆盖 image/video/text，提供身份、状态和能力快照。模型备注及来源胶囊消费元数据，不代表安装成功或质量通过。3D、统一参数 schema 和环境限制仍需补齐，不能把目录存在写成四类配置完成。实际装配和文件要求见 [MODELS](MODELS.md)、[模型合同](product/P-M13-model-provider-management.md)及[目录模块](../frontend/src/features/models/README.md)。

| 类别 | 当前可核对入口 | 仍需补齐 |
| --- | --- | --- |
| 图片 | 目录、图片提供方、本地装配与能力范围 | 统一 input/parameters/output、API 字段与环境策略 |
| 视频 | 目录、FL/Ref 装配、任务冻结参数 | 同上；未知字段和范围标待补 |
| 文本 | 本地及 Comfy 文本入口、提示词模板 | 统一字段表；DeepSeek 独立密钥通道已退役 |

会议输入中的 local 仅 open、external 可 open/closed 是待实现要求；它与执行路由“本地/API”是不同维度。未知开放属性、供应商参数与默认值不得由模型名猜测。产品“待验收场景”与历史差距表不是本轮执行证据。
