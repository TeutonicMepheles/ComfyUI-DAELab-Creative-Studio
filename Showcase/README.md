# Creative Studio Showcase

打开 [Creative-Studio-Showcase.json](Creative-Studio-Showcase.json)。这是可编辑的原生 ComfyUI 工作流，包含当前 9 类正式节点、23 个节点实例。打开后进入创作画布；按编号从素材、文稿、两表和两 LLM，查看到生成配置、剪辑及 H3 固定样例。

界面较窄时可横向平移；中键拖动平移，Ctrl + 滚轮缩放，“适应”查看布局。安装条件见 [安装指南](../docs/INSTALLATION.md)。

## 换一个隔离环境打开

先将 `assets/` 内文件复制到该 ComfyUI 的 `input/CreativeStudioShowcase/`，再拖入 JSON，或使用 Ctrl+O 打开。文件引用使用相对 `/view` 地址，不依赖机器盘符。也可执行：

```powershell
./Showcase/Install-ShowcaseAssets.ps1 -InputDirectory '你的隔离 ComfyUI/input'
```

脚本只复制本目录的示例素材，不更改节点安装、模型、服务或现有工作流。相同文件跳过；遇到不同的同名文件会停止。

## 素材与验收范围

素材为本地绘制的合成演示 PNG/MP4，不代表模型输出；来源与固定首尾帧见 [素材说明](assets/README.md)。便携工作流不包含本机任务回执或生成输出。文稿解析部分是预置示例，不作为 DOCX 解析验收。

08 分区引用固定 LOCAL-H3-001/002/003 条件；模型前提见 [模型配置](../docs/MODELS.md)。本轮文档整理没有运行模型或修改工作流、素材和参数。已有机器安装、实际导出、H3 冒烟及未覆盖项完整保留在 [2026-10-26 历史记录](../docs/validation/SHOWCASE_20261026.md)。
