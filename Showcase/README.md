# Creative Studio Showcase

打开 [Creative-Studio-Showcase.json](Creative-Studio-Showcase.json)。这是可编辑的原生 ComfyUI 工作流，包含当前 9 类正式节点、16 个节点实例。打开后进入创作画布；按编号从素材、文稿、两表和两 LLM，查看到生成配置与剪辑。

当前开发环境 `http://127.0.0.1:8280/` 已安装素材，并在工作流列表保存为 **Creative-Studio-Showcase**。右侧面板较窄时，可横向平移查看后续分区；中键拖动平移，Ctrl + 滚轮缩放，「适应」查看布局。

## 换一个隔离环境打开

先将 `assets/` 内文件复制到该 ComfyUI 的 `input/CreativeStudioShowcase/`，再拖入 JSON，或使用 Ctrl+O 打开。文件引用使用相对 `/view` 地址，不依赖机器盘符。也可执行：

```powershell
./Showcase/Install-ShowcaseAssets.ps1 -InputDirectory '你的隔离 ComfyUI/input'
```

脚本只复制本目录的示例素材，不更改节点安装、模型、服务或现有工作流。相同文件跳过；遇到不同的同名文件会停止。

## 展示范围与状态

- `assets/` 是本地绘制的合成演示素材，不代表模型输出；PNG 和 MP4 元数据已注明来源。`storyboard.txt` 提供对应的三镜头文字。
- 8280 当前为 CPU 隔离开发环境，未装配生成 provider。LLM/生成节点可以编辑和检查输入配置；模型请求、任务取消/恢复、真实结果回填仍需另行接入与执行。不要用顶层「运行」代替节点的生成操作。
- 本轮已在实际 ComfyUI 创作画布加载、检查媒体、保存，并通过剪辑节点完成本地 8 秒视频导出。生成任务仍为空，没有预造任务成功凭据。便携 JSON 不依赖本机导出任务记录。
- 文稿解析示例为明确标识的预置数据；完整 DOCX 导入、中文输入法、100 ms 性能预算与剩余 M6 验收没有因 Showcase 而被标记通过。
- 历史只读节点、旧样式原型、徽章/展厅/分割和外部 ComfyTV 可选节点不加入本工程；旧 LibTV 执行不迁入。
- Showcase 用于功能确认与继续编辑，不是 M6 通过或正式发布声明。
