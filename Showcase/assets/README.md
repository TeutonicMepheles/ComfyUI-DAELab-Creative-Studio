# Showcase 素材

本目录提供合成场景 PNG、四秒演示 MP4、分镜文字及 H3 固定首尾帧。由 `Showcase/Install-ShowcaseAssets.ps1` 复制到指定宿主的 `input/CreativeStudioShowcase/`。

`motion-first.png`、`motion-last.png` 与 `tests/fixtures/local-eval/images/` 的同名固定夹具逐字一致，保持红球与蓝色方块的输入条件。它们不是 H3 生成结果。

更改素材时同步工作流引用与 `Showcase/README.md`。安装脚本遇到不同内容的同名目标文件会停止；不要覆盖用户素材绕过检查。

不新增第三方许可授权；仓库源与许可边界见 [来源记录](../../docs/provenance/README.md)。素材更新需保留合成来源说明和固定评估输入，不能用真实生成结果替换固定夹具。
