# 结构化表格编辑 · 协作规则

继承仓库根 `AGENTS.md`。本目录职责、入口和定向验证见本目录 `README.md`。

编辑归属为 `frontend/src/features/table/`；`web/` 下对应文件只允许由构建生成，不能在副本另行维护实现或文档。

- 修改选择或视图状态不能隐式改动字段、结果或编辑历史；新增结构操作保留行列 ID 和未知字段。
- 素材单格支持追加多个素材；单素材及行/格投放保持快照。用户明确要求的素材组接列头使用真实原生持久连线与引用实例映射，不创建假连线，不合并同文件的不同引用。
- 输入性能改动用相同夹具检查可见提交、保存和撤销；微基准不能替代 100 ms 产品预算。
