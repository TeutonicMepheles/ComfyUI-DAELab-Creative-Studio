# 生成配置与任务会话

为表内和独立生成节点共用输入构造、设置、账本查询、恢复审阅和结果应用。

源码入口：table_generation_model.mjs：最终输入和配置；generation_session.ts：异步会话；table_generation_tasks.mjs：提交与恢复；video_tasks_panel.mjs：独立节点；task_snapshots.mjs：任务展示快照。

独立面板的 `isDocumentReady` 回调由宿主适配器提供；暂未就绪时不自动同步输入，显式修改仍拒绝执行，不绕过原生历史。

协作边界：后端 generation 服务拥有任务事实，前端仅保存引用和编辑输入。libtv_video_model.mjs 是保留格式/配置模型，不代表启用旧 LibTV 执行通道。

生成节点按实际连线自动识别表格、文字和图片。表格及 LLM 逐行结果单独接入，文字与图片可以组合；画布素材统一通过 Slot 接入，自动使用空闲兼容槽位，不显示用途选择菜单、不覆盖已有连线。旧槽位名称和序号保留，但接入不自动指定首尾帧或改变生成方式；在首帧／首尾帧任务的帧标签中通过 `@` 选择图片。节点正文不再提供“加入当前任务”快照落点。文生视频仅提交文字；参考模式提交已接入素材。旧正文投放副本与对应连线素材同步时合并，首尾帧及正文引用随素材身份迁移。断开文字／图片连线会清除该输入及对应任务的结果预览，仍连接的输入保留；断开表格或逐行来源后恢复空白任务，保留生成设置。清理随断线进入原生撤销记录，不删除服务账本或磁盘文件。输入识别由 generation_input.ts 维护，原生连线与画布共用。

任务栏仅在连接表格或 LLM 逐行结果时显示，用于切换批量任务，不提供新增任务加号。连接文字、图片或未连接时隐藏任务栏，直接编辑当前单个任务；断线、切换来源和重载均按实际连线更新。

表格或 LLM 注入模式的运行按钮提交全部尚无请求且无结果的任务，提示“生成剩余 N 个任务”；任务由共享服务排队，不依赖当前选中的卡片。已有结果、失败或待恢复的原请求不自动重提；全部已有请求时，当前任务仍沿用明确的恢复或重新生成入口。批量执行中的暂停覆盖该节点当前活动任务。积分文字标明当前任务的估算，不代表整批总额。

已保存的多任务节点即使缺失来源描述，也按批量入口执行。注入列表本身就是执行范围，节点内部遗留的行勾选标记不会将范围缩成第一行；源表格仍通过同步规则决定哪些任务进入节点。

提示词列表头按钮打开整列模型配置悬浮窗，关闭丢弃草稿；“应用全部”覆盖所有行（含未勾选行）的模型、模式及参数，并同步至连接的生成节点。配置保存在提示词列与各行中，无需新增生成列；已有生成列复用其配置所有者。重复应用也覆盖下游单独调整的配置，已生成结果保留。

首帧／首尾帧模式的整列配置可分别选择首帧、尾帧图片列，应用时取每行所选列中的第一张图片，无图片则留空。选择“保留逐行选择”不覆盖该角色已有图片；应用后仍可在单元格内单独换图，下次明确按列应用时才重新填充。

表格仅将勾选行同步为任务，任务始终按表格行顺序排列；取消勾选或删除行时移除对应任务，对排队、执行中或待恢复的请求调用现有暂停接口。取消勾选或删除行后按稳定行 ID 归档任务，保留回执、结果和单行配置并随工作流保存；重新勾选或撤销删除时恢复原任务与对应顺序。归档期间源表格明确修改的配置仍同步，节点单独覆盖在源配置未改变时保留；全不勾选时任务列表为空。服务账本和磁盘结果不删除。

用户取消执行中的任务或取消勾选对应行前，提示“当前任务正在进行中，确认取消吗？”；拒绝时保留任务及勾选状态。表头批量取消勾选只提示一次。生成节点删除表格任务时同步取消源行勾选。

表格与生成节点的参考缩略图中，已选为首帧或尾帧的图片显示对应文字，同一图片兼任两者时显示“首尾帧”；其余素材保留序号。表格按各行自己的配置标记，标记随当前任务、生成方式及图片选择更新。

生成节点的结果区合并当前已保存素材与任务账本中的已完成历史结果，并去重。修改输入、重新生成或重新加载工作流后，旧结果仍可查看；预览不写回当前输入、不创建新任务。断开素材输入仍清空对应预览，断线前的历史不会在轮询或重载时重新出现。

“输出为素材组”使用与预览相同的结果集合，包含已完成历史结果，按任务行顺序分组；仅跳过没有可用结果的行。输出保留原任务与素材身份，不要求将旧结果重新写回当前输入。

首帧／首尾帧模式的正文 `@` 菜单只提供文本列，图片通过帧选择入口填入，不自动切换生成方式。已有正文素材引用在提交前提示移除；帧绑定独立传给模型，不写成正文图片引用。

Seedance 和云端 MiniMax 的文生视频任务插入正文素材引用后自动切到全能参考；直接添加素材也会建立参考输入。生成节点不显示提示词来源下拉框，表格任务沿用源表格指定的提示词列。

表格导入任务的可编辑素材列同时建立参考绑定，无需在正文逐张插入 `@`。同步、移除素材和旧工作流重载时更新绑定；参考模式提交这些素材，文生模式不提交，首尾帧模式沿用帧选择。绑定不包含当前生成结果列，不修改已有任务回执。

生成方式仅显示当前模型能力接口声明的模式，不补充通用选项或已保存的不支持模式；读取失败时不显示模式选项。首帧与首尾帧分别保留。多图和混合参考合并显示为“全能参考”，只有模型支持混合参考时才映射到混合模式。

本地 H3 Ref 是独立模型选项，通过参考素材与正文引用接收 1–9 张图片；不接受视频参考，也不使用 H3 FL 的加速 LoRA。表内和独立节点复用相同输入与任务服务，显式模型绑定见 [模型指南](../../../../docs/MODELS.md)。

单个生成通过原生 Autogrow 接入多个文字、图片和视频来源。文字按接入顺序换行追加，更新某个来源不改变顺序，断线只移除对应内容；图片转为多图参考时保留已接入的首尾帧图片。连接素材只更新参考区和任务的素材引用，不自动向提示词插入 `@` 标签；手动添加的引用保持不变。具体生成方式仍受所选模型支持范围约束。

单个模式的素材落点建立真实连线，拉线与拖动来源节点均可使用；同一来源到同一生成节点只允许一条线。素材组通过独立 Autogrow 输入连接，读取组内文字、图片和视频，并随组内容更新。表格批量任务的素材填充保持快照行为，重复填入同一素材不再追加副本。

本目录的可编辑源位于 `frontend/src/features/generation/`。若在 `web/` 看到同名文档，它是构建副本；回到源码修改，再从仓库根目录构建。所有下述命令均从仓库根目录执行。

```powershell
node --import ./tests/migrated_business/register.mjs --test tests/generation_frontend/session.test.mjs tests/generation_frontend/table_flow.test.mjs tests/migrated_business/generation_input_regression.test.mjs tests/migrated_business/table_generation_history.test.mjs
```


输入为编辑配置和稳定任务身份，输出为账本投影及经过文档票据批准的素材引用。表内外复用请求合同，模型能力由宿主绑定。尚无独立生成页面；[表格预览](../../../../dev/table/README.md) 提供真实设置界面和明确模拟结果，不调用模型。配置字段与真实验收见 [模型指南](../../../../docs/MODELS.md) 和 [状态](../../../../docs/validation/STATUS.md)。
## 积分估算

模型名称统一标注「（本地）」或「（Comfy）」，未知模型显示来源未知；存储的模型 ID 不变。生成节点在生成按钮左侧显示当前 Comfy 任务单次生成的预计积分，覆盖图片和视频模型。宿主适配层在本地计算已安装官方节点的价格公式，随模型、参数和实际参考素材更新；区间价格保留区间。空提示词可预估价格，提交仍要求有效提示词。本地模型不显示积分，缺少价格公式或输入无法解析时显示无法估算。估算不提交任务、不保存到账本，实际扣费以平台为准。

## 自动输出素材

新请求通过预检后，生成节点自动连接一个占位素材节点；排队、进度、暂停、失败和待恢复状态显示在占位内。已核验的图片／视频直接更新该节点，节点 ID 与连线保持不变。已有自动输出的结果不再重复展示在生成面板下方；旧工作流结果仍可在面板查看。

表格与 LLM 逐行任务共用一个输出素材组，生成节点只连到组容器，组内素材不再逐个连线；成员通过保存的组身份接收更新。按执行中、等待、异常待处理、暂停停止、完成排序，同状态按原任务行顺序排列。重新生成创建新输出，保留旧素材；锁定组不自动重排，断开来源的组不被新任务自动重连。组输出仅包含已就绪素材，占位仍可见；全部未就绪时禁止整组消费。删除或断开输出组、移出成员后，轮询不重新创建或写入对应目标。旧工作流的单素材直连仍可读取。复制输出作为独立素材，不继承任务写入权限。

`generation_output_nodes.ts` 在宿主边界持有请求与输出节点的关联；任务服务只通过 prepared/report 回调提供数据，仍由 SQLite 保存执行事实。输出使用已有 `DAELAB.MediaUpload`，追加可选惰性 `source_report` 输入关联生成节点的既有 `task_report` 输出。该线表示请求来源，执行读取输出节点自身素材，不执行上游当前选择的任务。原有输出槽位和素材 JSON 保持兼容。

定向检查：`tests/migrated_business/generation_output_nodes.test.mjs`、`tests/generation_frontend/table_flow.test.mjs`；实际环境范围见 [输出占位验证](../../../../docs/validation/GENERATION_OUTPUTS_20261030.md)。
